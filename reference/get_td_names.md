# Returns the available asset names at the Tesouro Direto (TD) website

Returns the available asset names at the Tesouro Direto (TD) website

## Usage

``` r
get_td_names()
```

## Value

A character vector of names.

## Examples

``` r
get_td_names()
#> [1] "LFT"             "LTN"             "NTN-C"           "NTN-B"          
#> [5] "NTN-B Principal" "NTN-F"          
```
